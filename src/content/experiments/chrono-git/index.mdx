## Overview

Chrono-Git transforms your repository's history into an interactive 4D visualization powered by WebGPU.

### Features
- Real-time particle system rendering
- Branch topology visualization
- Contributor activity mapping
- Time-travel navigation

### Performance
Leveraging WebGPU's compute shaders, Chrono-Git can render repositories with 100k+ commits at 60fps.
